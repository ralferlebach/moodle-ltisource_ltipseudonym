# Disclosure trace

Generated by `tests/disclosure_trace_test.php` (PHPUnit, Moodle 4.5.15+ (Build: 20261021)) and, for the real two-site capture, by `tests/playwright/disclosure_capture.spec.js`. Do not edit by hand: regenerate with `LTIPSEUDONYM_TRACE_OUT=<dir>` (see docs/TESTING.md). Machine-readable: `tests/fixtures/disclosure_trace.json` and `tests/fixtures/disclosure_trace_e2e.json`.

**Redaction:** no real value is stored. Every value is replaced by its class: `local_user_id` (the Moodle user id), `pseudonym` (a token of this plugin), `name`, `email`, `username`, `idnumber`, `contains_local_user_id` (a structure that carries the local id, e.g. the LTI 1.1 result id), `contains_session_key` (a URL with the Moodle session key), `service_url_proxy` / `service_url_core`, `empty` (present with an empty value), `no_user_identifier`. A claim that is not listed is absent.

Tool registrations of the capture: **full** shares names, e-mail and grades and has custom parameters with user variables (`$User.id`, `$User.username`, `$Person.email.primary`, `$Person.name.full`, `$Person.sourcedId`, `$Result.sourcedId` in the activity); **quiet** shares nothing. Both have AGS and NRPS. Policies are stored at the tool level (the site scope at the site level, where it is chosen); `remove` is set for every category that can be removed (`blank` for the ID number).
